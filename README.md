\# Event Commerce



Event-driven e-commerce platform built with:



\- Java 21

\- Spring Boot

\- Apache Kafka

\- PostgreSQL

\- Docker

\- Maven



\## Architecture



The system will contain multiple microservices communicating through Kafka events.



\## Services



\- Order Service

\- Payment Service

\- Inventory Service

\- Notification Service

\- Analytics Service
